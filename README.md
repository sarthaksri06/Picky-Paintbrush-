# Picky the Paintbrush - Color Memory Game

A fun, cartoonish color memory game built for mobile and YouTube Playables. Help Picky the Paintbrush remember his colors!

## Play Now

[Play on GitHub Pages](https://sarthaksri06.github.io/picky-paintbrush/)

## How to Play

1. Picky shows you a color for a few seconds
2. Memorize it carefully!
3. Use the sliders to match Picky's color
4. See how close you got!
5. Help Picky through 5 rounds!

## Difficulty Levels

- **Easy**: 3 seconds to memorize
- **Medium**: 2 seconds to memorize  
- **Hard**: 1.5 seconds to memorize

## Features

- Kid-friendly 
- Custom SVG illustrations
- Mobile-optimized touch controls
- Web Audio API sound effects
- Local leaderboard with best scores
- Confetti celebrations for high scores
- Landscape mode support

## Tech Stack

- HTML file
- Pure CSS animations
- Vanilla JavaScript
- Web Audio API for synthesized sounds
- localStorage for score persistence
